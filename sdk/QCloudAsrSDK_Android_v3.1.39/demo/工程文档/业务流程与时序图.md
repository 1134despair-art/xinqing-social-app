## 业务流程与时序图

本文档聚焦于 3 个 SDK 模块的**业务调用链**（App 如何调用 SDK）以及 SDK 内部的**关键交互时序**（音频采集/网络请求/签名/服务端回包）。

---

## `speech-demo` 调用概览

```mermaid
sequenceDiagram
  autonumber
  participant UI as UI（Activity）
  participant CFG as BuildConfig/DemoConfig
  participant RT as asr-realtime
  participant OS as asr-one-sentence
  participant FR as asr-file-recognize

  UI->>CFG: 读取 `AppId/SecretId/Secretkey`
  UI->>RT: 进入实时识别页面（创建 `AAIClient`）
  UI->>OS: 进入一句话识别页面（创建 `QCloudOneSentenceRecognizer`）
  UI->>FR: 进入极速文件识别页面（创建 `QCloudFlashRecognizer`）

  Note over UI,FR: Demo 只是调用方，网络/签名/音频线程均在 SDK 内部完成
```

## `asr-realtime`（实时识别）

```mermaid
sequenceDiagram
  autonumber
  participant App as App/Demo
  participant Client as `AAIClient`
  participant Task as `AudioRecognizeTask`
  participant AR as `AudioRecognizer`（音频线程）
  participant WS as `WebsocketHelper`（网络线程）
  participant Opus as `QcloudAsrRealtimeUtilsNative`/OpusEncoder
  participant S as 云端 ASR

  App->>Client: startAudioRecognize(request, listeners, config)
  Client->>Task: start()
  Task->>AR: start() 采集/切片
  Task->>WS: websocketConnect(request)
  WS->>S: wss connect（signed url）
  S-->>WS: onOpen
  WS-->>App: onStartRecord

  loop 每个音频分片
    AR-->>Task: onSliceComplete(pcm)
    alt config.isCompress()==true
      Task->>Opus: encode(PCM->Opus)
      Task->>WS: sendMessage(opus bytes)
    else 未压缩
      Task->>WS: sendMessage(pcm bytes)
    end
    S-->>WS: JSON result
    WS-->>App: onSliceSuccess（中间态）
    opt slice_type==2
      WS-->>App: onSegmentSuccess（稳态）
    end
  end

  App->>Client: stopAudioRecognize()
  Task->>WS: sendEnd({"type":"end"})
  S-->>WS: final==1
  WS-->>App: onSuccess(all text)
  WS-->>App: onStopRecord（服务端断联）
```

## `asr-one-sentence`（一句话识别）

```mermaid
sequenceDiagram
  autonumber
  participant App as App/Demo
  participant Rec as `QCloudRecorder`
  participant R as `QCloudOneSentenceRecognizer`
  participant T as `QCloudRecognizeBaseAsyncTask`
  participant Sign as `QCloudSignUtil`
  participant S as 云端 ASR

  alt 直接调用 recognize(audioData)
    App->>R: recognize(audioData, format, frequence)
  else 使用内置录音器
    App->>R: recognizeWithRecorder()
    R->>Rec: start(voicePath)
    Rec-->>App: onVolume(val)
    App->>R: stopRecognizeWithRecorder()
    R->>Rec: stop()
    R->>R: 读取录音文件 bytes
  end

  R->>T: new task(params).execute()
  T->>Sign: sign(headers, params)
  T->>S: HTTPS POST JSON（Authorization: TC3-HMAC-SHA256 ...）
  S-->>T: response
  T-->>R: onPostExecute(result)
  R-->>App: callback.recognizeResult(result, exception)
```

## `asr-file-recognize`（极速文件识别）

```mermaid
sequenceDiagram
  autonumber
  participant App as App/Demo
  participant R as `QCloudFlashRecognizer`
  participant T as `QCloudFlashRecognizeBaseTask`
  participant Sign as `LocalCredentialProvider`
  participant S as 云端 ASR

  App->>R: recognize(params)
  R->>T: new task(params).execute()
  T->>T: 组装 query（含 secretid 等）
  T->>Sign: getAudioRecognizeSign("POST" + urlString)
  alt params 含 DATA
    T->>S: HTTPS POST octet-stream（写入 byte[]）
  else params 含 PATH
    T->>T: 分块读取文件（避免 OOM）
    T->>S: HTTPS POST octet-stream（逐块写入）
  end
  S-->>T: response
  T-->>R: onPostExecute(result)
  R-->>App: callback.recognizeResult(result, exception)
```
