## 工程架构图

本文档聚焦于仓库 `cloud-asr-sdk-android2` 的**模块划分**与**内部层次结构**（API 层 / 任务编排 / 音频层 / 网络层 / Native 层），用于快速理解工程全貌。

---

## 整体架构图（模块/层次）

### 1. 实时识别 SDK 架构

```mermaid
flowchart TB
  subgraph APP1["Demo App"]
    Demo1["speech-demo<br/>实时识别页面"]
  end

  subgraph RT_SDK["asr-realtime SDK"]
    RT_API["API外观层<br/>AAIClient/AAIImpl"]
    RT_TASK["任务编排<br/>TaskManager/AudioRecognizeTask"]
    RT_AUDIO["音频层<br/>AudioRecognizer/PcmAudioDataSource"]
    RT_WS["网络层<br/>WebsocketHelper/WebsocketParamUtils"]
    RT_JNI["JNI/Native<br/>QcloudAsrRealtimeUtilsNative"]
    RT_OPUS["libopus<br/>OpusEncoder"]

    RT_API --> RT_TASK
    RT_TASK --> RT_AUDIO
    RT_TASK --> RT_WS
    RT_AUDIO --> RT_JNI
    RT_JNI --> RT_OPUS
  end

  Demo1 --> RT_API
  RT_WS -->|WebSocket wss| Cloud1["腾讯云ASR服务端"]
```
